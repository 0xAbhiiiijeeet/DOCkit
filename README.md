# 📄 DOCkit

> Smart. Offline. Ad-Free.  
> Made for everyday use.

A powerful Android document scanner application built to make scanning, organizing, and sharing documents fast, private, and effortless without ads or cloud dependency.

---

## ✨ Features

- 📸 Smart Document Scanning
- ✂️ Auto Edge Detection
- 🧠 ML Kit Powered Scan Technology
- 🖼️ Perspective Correction & Enhancement
- 📄 One Tap PDF Generation
- 📂 Document Management System
- 📴 Fully Offline Functionality
- 🔒 100% Private & Secure
- 🚫 No Ads
- ♾️ No Page Limit

---

## 🛠️ Tech Stack

- Kotlin
- Jetpack Compose
- MVVM Clean Architecture
- Google ML Kit
- Room Database
- Material Design 3

---

## 🚀 Installation

```bash
git clone https://github.com/YOUR-USERNAME/DOCkit.git
```

1. Open the project in Android Studio
2. Sync Gradle
3. Run on emulator or physical device
